- Always `cd` to `./app/web/` before running any `npm` or `bun` commands.
- Run `npm run lint` before opening a pull request.
- Read from https://daisyui.com/llms.txt before writing any daisyUI code
- Ask permission before installing production dependencies
- Run python tests with `uv run pytest --tb=line`
